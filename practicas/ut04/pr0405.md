# PR0405. Limpieza de logs

## 1.- Objetivo

Eres el ingeniero de seguridad de una plataforma de comercio electrónico. Un microservicio antiguo registra las peticiones HTTP con URLs sucias, direcciones IP expuestas que incumplen la normativa de privacidad (GDPR), y códigos de error con formatos internos complejos.

El departamento legal y de desarrollo necesita un informe limpio en CSV para analizar el tráfico anómalo **sin exponer las IPs completas** de los usuarios y **eliminando los parámetros de sesión basura** de las URLs.

No puedes cambiar el servicio web. Debes crear un script en PowerShell que manipule las cadenas de texto utilizando los métodos que consideres necesarios y las exporte de forma estructurada.


## 2.- Datos de entrada

Copia y pega este bloque de texto en tu script dentro de una variable en bloque:

```powershell
$logsWeb = @"
POST /api/v1/auth/login?session=a8f93j2&token=expired [IP: 192.168.10.45] [Agent: Mozilla/5.0] [ERR-0040-AUTH]
GET /api/v2/products/search?q=laptop&sort=asc [IP: 10.0.2.15] [Agent: Chrome/110.0] [ERR-0200-OK]
DELETE /api/v1/admin/drop_table?confirm=true&force=1 [IP: 172.16.254.88] [Agent: ScriptBot/1.2] [ERR-0500-FATAL]
GET /api/v1/user/profile?id=9921&token=xyz [IP: 192.168.10.102] [Agent: Firefox/109.0] [ERR-0403-FORBIDDEN]
"@
```

Observa la estructura. Las líneas no están separadas por un delimitador simple, lo que te obligará a buscar posiciones de caracteres y extraer fragmentos específicos.

## 3.- Los requisitos de manipulación de cadenas

Tu script debe procesar `$logsWeb` línea por línea aplicando obligatoriamente las siguientes operaciones sobre cadenas:

1. **Extracción y limpieza de la ruta HTTP:**
    - Debes separar el método HTTP (`GET`, `POST`, `DELETE`) de la ruta de la URL.
    - **Limpieza de parámetros:** las URLs contienen parámetros de consulta a partir del signo de interrogación (`?`). Debes eliminar todo lo que hay desde el `?` en adelante para quedarte únicamente con la ruta limpia (ej. `/api/v1/auth/login?session=...` debe pasar a ser `/api/v1/auth/login`).
2. **Enmascaramiento de IP:**
    - Extrae la dirección IP que se encuentra dentro de los corchetes `[IP: ...]`.
    - Por normativas de privacidad, **debes ocultar el último octeto de la IP** sustituyéndolo por asteriscos utilizando manipulación de cadenas (por ejemplo, cortando la cadena hasta el último punto o reemplazando el tramo final). Ejemplo: `192.168.10.45` debe convertirse en `192.168.10.***`.
3. **Procesamiento de códigos de error:**
    - Al final de cada línea aparece un código como `[ERR-0040-AUTH]`.
    - Debes extraer únicamente el número central del error (por ejemplo, de `ERR-0040-AUTH` debes aislar el código numérico `0040`).
4. **Filtrado de seguridad:**
   - Solo debes incluir en el informe aquellas peticiones cuyo código de error **no** sea correcto (es decir, ignora los que contengan `ERR-0200-OK`). Solo interesan errores, bloqueos o fallos (`0400`, `0500`, `0403`, etc.).
5. **Salida estructurada:**
   - Genera objetos **PSCustomObject** con las columnas limpias y expórtalos a un archivo llamado `auditoria_web.csv`.



## 4.- Resultado esperado

Al abrir el archivo `auditoria_web.csv` generado, la tabla resultante debe mostrar los datos transformados de esta forma:

| Method   | CleanPath                  | MaskedIP         | ErrorCode | Agent           |
| -------- | -------------------------- | ---------------- | --------- | --------------- |
| `POST`   | `/api/v1/auth/login`       | `192.168.10.***` | `0040`    | `Mozilla/5.0`   |
